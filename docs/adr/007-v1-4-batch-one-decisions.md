# ADR-007：v1.4 第一批实现决策

## 状态

已接受。

## 背景

ROADMAP 将 v1.4 定为“高级工具与体验”：颜色转换、进制与位运算、文本处理、Mock 数据生成、本地收藏与最近使用、PWA 离线。实现前需要确认四个技术点：Mock 随机流的确定性、位运算的数值语义、离线缓存策略、本地偏好与分享状态的边界。

## 决策

1. **Mock 数据使用可种子化的确定性随机流**
   - 种子非空时使用 xmur3（字符串哈希）+ mulberry32（PRNG）生成随机流；同种子同模板输出完全一致，便于测试、复现与分享调试场景。
   - 种子为空时退回 `Math.random`，保持日常使用的随机性。
   - 占位符 DSL 保持纯函数实现于 `core.js`，Node 测试覆盖确定性与边界错误。
2. **进制与位运算基于 BigInt 的 64 位无符号语义**
   - 不使用 JavaScript 32 位按位运算符，避免精度与符号位歧义。
   - 全部数值限制在 0 到 2^64-1；NOT 返回 64 位补码，左移结果掩码回 64 位，移位位数 0-63。
   - 自动进制识别仅依据 0x / 0b / 0o 前缀与字符集（纯数字按十进制，含 a-f 按十六进制），歧义输入要求显式选择进制。
3. **PWA 采用版本化预缓存 + 同源 cache-first**
   - `sw.js` 预缓存站点全部静态资源；运行时对同源 GET 请求 cache-first、网络回填缓存，离线回退缓存的 `index.html`。
   - 缓存名携带版本号，新 SW 激活时删除旧缓存并 `skipWaiting` / `clients.claim`，发布后刷新即可拿到新版本。
   - 仅在 https 或 localhost 注册；Pages 子路径通过相对路径 `./sw.js` 天然兼容。
   - 图标使用单个 SVG（purpose `any maskable`），不引入位图生成流程。
4. **收藏与最近使用只存本地，不进分享状态**
   - localStorage 键：`devtools-favorites`（上限 12）、`devtools-recent`（上限 8，导航展示去重收藏后的前 5）。
   - 与主题偏好一致，不参与 URL hash 分享；localStorage 不可用时静默降级。
5. **四个新工具沿用既有零依赖纯函数模式**
   - 全部实现于 `core.js`，复用 `success` / `idle` / `failure`、输入上限与 URL 状态编码，不引入运行时依赖。

## 备选方案

### 方案 A：Mock 使用 faker 类库

优点：数据种类丰富。

缺点：引入大体积运行时依赖或 CDN，违反零依赖静态部署（ADR-002）；中文姓名 / 大陆手机号等本地化需求仍需定制。

### 方案 B：位运算使用 JavaScript 32 位运算符

优点：实现最简单。

缺点：与开发者日常面对的掩码、位移（常为 64 位）不一致，溢出行为难以解释。

### 方案 C：Service Worker 采用 network-first

优点：更新及时。

缺点：离线场景响应慢且依赖网络超时，工具箱内容更新频率低，cache-first + 版本化缓存收益更高。

## 后果

1. Mock 工具的占位符集合是文档化子集，后续按需扩展 DSL，不影响既有模板。
2. 进制工具对超过 64 位或负数输入明确报错，边界在页面说明。
3. 每次发布需要更新 `sw.js` 中的缓存版本号，否则老缓存可能延迟更新。
4. 收藏 / 最近使用依赖 localStorage，跨设备不同步（符合隐私边界预期）。
