## 当前限制

1. 本会话环境无法绑定本地端口，`python3 -m http.server` 无法在沙箱内启动。
2. 当前环境也没有可用的受控浏览器实例，因此尚未完成真实浏览器手工验收。
3. 正则、复制和分享能力依赖浏览器 API，自动化测试尚未覆盖 Worker、Clipboard 和 hash 路由端到端流程。
4. GitHub Pages 部署需要仓库推送后才能执行，当前尚未验证线上 Pages 地址。
